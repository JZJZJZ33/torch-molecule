# Upstream source

The model implementation in this directory is adapted from the Apache-2.0
licensed `liugangcode/Llamole` Graph-DiT decoder. It is kept separate from the
repository's original Graph-DiT implementation because the downloaded
`Llamole-Pretrained-GraphDiT` checkpoint uses different module names and layer
definitions.

Upstream: https://github.com/liugangcode/Llamole/tree/main/src/model/graph_decoder
