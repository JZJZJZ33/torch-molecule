How the property predictor understands polymers

Two polymer-specific representation methods connect repeat-unit structure with material-property prediction.

Repetition-invariant graph predictor

The predictor represents a polymer as a molecular graph and learns features that remain stable when the same repeat unit is expanded into longer chains.

  1. Polymer-aware augmentation creates equivalent chains with different repetition lengths during learning.
  2. Graph message passing combines atom and bond information across the structure.
  3. Invariant pooling and regression produce a material-property estimate that is less sensitive to how the repeat unit was written.

Multimodal polymer representation

This method learns from both a polymer string and its three-dimensional conformation so chemical connectivity and spatial geometry can inform the same prediction.

  1. 1D representation network reads masked pSMILES and learns chemical sequence context.
  2. 3D representation network learns from noisy atomic coordinates and molecular geometry.
  3. Multitask pretraining reconstructs masked tokens, denoises coordinates, and aligns both latent representations before property fine-tuning.
